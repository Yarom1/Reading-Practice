# קוראים בכיף 🦉📖

אפליקציית Android ללימוד קריאה בעברית לילדים. ינשופי, הדמות המלווה, מקריא כל שורה, מדגיש כל מילה בזמן שהיא נשמעת, ומזמין את הילד לקרוא בעצמו – בלי לחץ, בלי ציונים ובלי עונשים.

- **41 קטעי קריאה מקוריים** בחמש רמות, עם ניקוד מלא, ובכתיב מלא כשמכבים את הניקוד
- **הדגשת מילים מסונכרנת** עם ההקראה (לפי אירועי מנוע ההקראה, או מילה אחר מילה כמנגנון חלופי – אף פעם לא לפי טיימר)
- **"עכשיו תורך"**: אחרי כל שורה הילד קורא לבד ולוחץ "סיימתי לקרוא"; אפשר לשמוע שוב או "לקרוא יחד לאט"
- **מצב קריאה לבד**, כרטיס מילה (לחיצה ארוכה), "המילים שלי"
- **6 משחקי קריאה**, כוכבים, מדליות, וינשופי שמקבל אביזרים חדשים
- **פנייה בלשון זכר/נקבה** לפי הילד
- **אזור הורים מוגן בקוד**: דוחות, הגדרות, בחירת קול ומהירות, הוספת טקסטים משלכם, כמה ילדים במכשיר אחד
- **פרטיות**: אין הרשאת אינטרנט, אין מיקרופון, אין פרסומות; הכול נשמר במכשיר

האפיון המעודכן נמצא ב-[docs/SPEC.md](docs/SPEC.md).

## התקנה

1. מורידים את קובץ ה-APK האחרון מעמוד ה-**Releases** של המאגר, או מה-Artifacts של ה-Action האחרון (Actions ← Build APK).
2. פותחים את הקובץ במכשיר האנדרואיד ומאשרים "התקנה ממקורות לא ידועים" אם המכשיר מבקש.
3. **קול עברי:** ההקראה משתמשת במנוע ההקראה של המכשיר. מומלץ "שירותי הדיבור של Google" עם הקול העברי מורד למכשיר (הגדרות ← נגישות/שפה ← פלט המרת טקסט לדיבור). בהתקנה הראשונה האפליקציה בודקת זאת ומכוונת להתקנה אם צריך.

נדרש Android 8.0 ומעלה.

## בנייה

הבנייה רצה אוטומטית ב-GitHub Actions בכל push (`.github/workflows/android.yml`): קומפילציה, בדיקות יחידה, בדיקות ממשק (Robolectric) עם צילומי מסך, ו-APK חתום. ב-push ל-`main`, או כשהודעת ה-commit כוללת `[release]`, או בהרצה ידנית – נוצר גם Release עם ה-APK.

מקומית (עם Android SDK):

```bash
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # בדיקות יחידה + ממשק
```

### חתימה

כדי שאפשר יהיה לעדכן את האפליקציה בלי למחוק אותה, כל הגרסאות נחתמות באותו מפתח. כברירת מחדל זה המפתח שב-`app/signing/` (שמור במאגר, ולכן אינו סודי). להפצה ציבורית (למשל Google Play) כדאי לעבור למפתח פרטי: מוסיפים ב-GitHub את הסודות `SIGNING_KEYSTORE_BASE64`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`. שימו לב: אחרי החלפת מפתח צריך להסיר פעם אחת את הגרסה הקודמת מהמכשיר.

## מבנה הקוד

```
app/src/main/java/com/korimbekef/reading/
  core/        לוגיקה טהורה: טקסט עברי וניקוד, תוכן, כוכבים/מדליות/רצפים, משחקים
  data/        Room (התקדמות, פרופילים), DataStore (הגדרות), מאגר תוכן
  speech/      מנוע ההקראה וסנכרון ההדגשה (TtsSpeechController)
  audio/       צלילי משחק קצרים
  ui/          Jetpack Compose: מסכי ילד, מסך קריאה, משחקים, אזור הורים
app/src/main/assets/content/
  passages.json   קטעי הקריאה ({ניקוד|כתיב מלא} למילים שהכתיב שלהן שונה)
  vocabulary.json המילון המצויר
```

### הוספה או עריכה של תוכן

כל שורה ב-`passages.json` נכתבת עם ניקוד. כשהכתיב המלא (בלי ניקוד) שונה מהכתיב המנוקד, כותבים `{צִפּוֹר|ציפור}`. הבדיקה `ContentValidationTest` מוודאת שהשורות תקינות (אותן מילים בשתי הגרסאות, ניקוד תקין מבנית, כתיב מלא סביר). מומלץ שמורה או מגיה יעברו על הניקוד.
